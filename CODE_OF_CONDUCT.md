# Código de conduta

Este projeto segue o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, critique ideias e código (não pessoas), acolha quem está começando e não exponha dados de ninguém, nem os seus nem os de outras pessoas.

Comportamento abusivo pode ser informado ao mantenedor pelo [aviso privado do GitHub](https://github.com/duduferaso/ha_local_assistant/security/advisories/new) ou pelo perfil @duduferaso. Toda denúncia é tratada em sigilo.
